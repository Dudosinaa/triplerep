# Home — модель по приложенной планировке

`Home.prefab` — готовая модель. Экземпляр размещён в `Assets/Scenes/Home.unity`.
Масштаб: 1 единица Unity = 1 метр. Пол на Y = 0, потолок на Y = 2.7.
Начало координат — внутренний юго-западный угол квартиры, X направлен вправо
по плану, Z — к окнам. Модель содержит собственные сохранённые Mesh assets,
материалы URP и BoxCollider для каждого сплошного участка.

## Геометрия

- Наружные стены, перегородки спальни и санузла, С-образная техническая ниша.
- Два оконных проёма, входной, спальный и санузловой дверные проёмы.
- Сплошная плита пола, отделка пола и отдельная плита потолка.
- `Ceiling` можно скрыть для осмотра сверху; в сохранённой сцене он включён.
- `Openings` содержит именованные точки центров проёмов.
- Мебель, сантехника, дверные полотна и остекление не входят в модель.

## Размеры и допущения

Источник — растровый план, а не обмерный CAD-файл. Размеры в миллиметрах.
Приоритет отдан подписанным верхней и левой цепочкам размеров:
ширина внутри 2800 + 100 + 2825 = 5725 мм;
глубина 3583 + 100 + 1900 + 350 = 5933 мм.
Некоторые нижние/правые цепочки и графические линии не полностью совпадают;
неподписанные элементы восстановлены по пропорциям рисунка.

| Параметр | Принято | Основание |
| --- | --- | --- |
| Высота до потолка | 2700 мм | Допущение: на плане нет высот |
| Двери: высота | 2100 мм | Допущение |
| Окна: ширина | 1500 мм каждое | Размеры на плане |
| Окна: низ / верх | 900 / 2400 мм | Допущение |
| Смещения окон от левого края соответствующей комнаты | 830 / 535 мм | Размеры на плане |
| Боковые и входная наружные стены | 250 мм | По рисунку |
| Наружная стена с окнами | 420 мм | По рисунку |
| Перегородки | 100 мм | Подписанная толщина и рисунок |
| Вход: ширина | 950 мм | По рисунку |
| Спальня: ширина проёма | 750 мм | По рисунку; размер 900 относится к проходу возле кровати |
| Санузел: ширина проёма | 700 мм | По рисунку |
| Плита пола / потолка | 180 / 150 мм | Допущение |

Дверь спальни обозначена на плане как дверь-пенал. В модели оставлен
свободный проём; механизм и внутренний карман под полотно не моделировались.
Штриховая восточная грань технической ниши оставлена открытой.

## Редактирование и проверка

Исходные размеры собраны в `Editor/HomeBuilder.cs`, метод `DefineGeometry`.
Меню Unity: `Tools > Home > Rebuild model and place in Home scene`.
Генератор обновляет свои Mesh assets и prefab, заменяет только его экземпляр
и созданный им свет в Home. Остальные объекты сцены сохраняются.
Повторная генерация сбрасывает правки самого сгенерированного prefab.

`Tools > Home > Validate saved model and scene` проверяет сохранённую сцену,
наличие ровно одного экземпляра, активный потолок, геометрию и UV2,
свободные проёмы, коллизии подоконника/перемычки, уровни пола и потолка.
`Build and render previews` также создаёт изображения в `Logs/Home`.
В сцене настроены камера внутри гостиной и отдельная группа света.
