# Прозрачные окна Metro_Unity

Созданы отдельные материалы стекла без изменения существующих 107 материалов и исходного FBX. Изменения исходных файлов сцены и настроек проекта не требовались.

## Результат

- 21 боковой оконный меш использует WindowGlass_LateralTren.
- 40 стёкол боковых дверей используют WindowGlass_PuertasLaterales.
- 15 стёкол передних дверей используют WindowGlass_PuertaDelantera.
- Вся группа CristalesFrontalesCabezaTren_LP.001–.020 (20 объектов) остаётся непрозрачной и использует исходные Black/PuertaDelantera. WindowGlass_Cab больше не назначается этим объектам.
- Рамы, резиновые уплотнения, кузов, двери, сиденья, внутренние перегородки и станция сохраняют исходные материалы.

В Textures/Glass созданы три RGBA-текстуры. RGB точно скопирован из исходного albedo, A — из красного канала соответствующей opacity-карты. Значения проверены по каждому пикселю сохранённых PNG: 6291456 пикселей. Оригинальные JPEG/PNG и настройки их импорта не изменены.

Стекло использует URP/Lit, Transparent/Alpha с сохранением отражений, Metallic = 0, Smoothness = 0.72, Normal Strength = 0.25. Общий множитель альфа = 0.85; для однотонного стекла кабины — 0.16. Запись в глубину и отбрасывание непрозрачной тени выключены. Грязные края сохраняют большую непрозрачность благодаря маске.

## Назначение

Materials/Editor/MetroWindowGlassPostprocessor.cs обрабатывает только Models/Metro_Unity.fbx. Он назначает новые материалы по точному списку имён оконных мешей и проверяет семейство исходного материала. Общие исходные материалы не редактируются. Для сохранения прозрачных окон при повторном импорте этот Editor-скрипт должен оставаться в проекте.

## Проверки

- Unity завершил компиляцию и импорт; в Scene салон виден сквозь боковое окно, кузов и рамы непрозрачны.
- Проверен импортированный FBX: 4505 MeshRenderer, из них 76 используют ожидаемые отдельные материалы стекла, у остальных 4429 все слоты совпадают с состоянием до обработки окон. Ошибок итоговой сверки нет.
- baseline-renderers.json содержит перечень исходных объектов и связей FBX. import-baseline.json содержит реальные слоты Unity до назначения стекла: Unity может переупорядочивать подключения FBX к подмешам и заменять материал вырожденного меша стандартным.
- unity-validation.json содержит итоговые результаты. Проверку можно повторить через Tools > Metro > Validate Window Glass после импорта модели.
- По SHA-256 все 868 ранее существовавших файлов внутри Models, Materials и Textures совпали с состоянием до этой настройки. Файл Train.unity также не изменился.

Изменения состоят только из новых файлов в Materials и Textures. Исходные два предупреждения FBX об отсутствии нормалей остались без изменений.

## Уточнение по фото

По указанию пользователя вся группа CristalesFrontalesCabezaTren_LP исключена из прозрачных окон. После повторного импорта проверены 4505 объектов: 76 прозрачных оконных мешей, 4429 с исходными назначениями, ошибок нет. Изменены только правило в Editor-скрипте и данные проверки; все материалы, текстуры и FBX сохранены без изменений.
